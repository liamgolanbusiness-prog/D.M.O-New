# DMO Architects — Website

אתר תדמית למשרד אדריכלות **די אם או DMO אדריכלים בע"מ**.
אתר סטטי, בעברית RTL, Mobile-First, מונפש, עם אפקטי גלילה ותלת־ממד בכותרת.

## תכונות
- עברית RTL, נגיש, סמנטי
- Mobile-First עם breakpoints ב־640 / 900 / 1200
- Hero מונפש עם ציור תלת־ממד על קנבס (ללא תלויות)
- אפקטי גלילה (reveal, parallax, progress bar, smooth scroll)
- מטא תגיות SEO, OG, Twitter, JSON-LD LocalBusiness
- כפתור וואטסאפ צף, קישורי רשתות חברתיות
- טופס יצירת קשר מלא (demo submission)
- גלריית פרויקטים עם סינון
- קרוסלת המלצות עם swipe
- תפריט נייד, כפתור חזרה למעלה, מצב high-contrast, prefers-reduced-motion

## מבנה
```
/
├── index.html
├── robots.txt
├── sitemap.xml
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── img/*.jpg
```

## פיתוח מקומי
פתחו את `index.html` בדפדפן, או הריצו שרת סטטי:
```bash
npx serve .
```

ניתן לפרוס ישירות ל־GitHub Pages, Netlify, Vercel וכד' — אין תהליך build.
